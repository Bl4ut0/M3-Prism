# Contributing to M3 Prism

First off, thank you for considering contributing to M3 Prism! It's people like you that make M3 Prism a powerhouse for everyone.

## How to Contribute

### 1. Sign the CLA
By contributing to this project, you agree to the terms of the [Contributor License Agreement (CLA)](CLA.md). This allows us to keep the project open-source while also maintaining the ability to release the app on official mobile stores.

### 2. Reporting Bugs
- Use the GitHub Issue Tracker.
- Describe the bug and include steps to reproduce.
- Mention your platform (Windows, Android, etc.) and what media format you were playing.

### 3. Feature Requests
- We love new ideas! Open an issue and label it as `enhancement`.

### 4. Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes.
4. Make sure your code lints.
5. In your PR description, confirm that you agree to the M3 Prism CLA.

## Style Guide
- Follow the existing coding style in the repository.
- Use descriptive commit messages.
- Keep components focused and reusable.

Thank you for your help in making M3 Prism the ultimate multimedia player!
